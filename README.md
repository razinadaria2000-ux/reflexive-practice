# Рефлексивная практика

Первая рабочая версия веб-приложения для самонаблюдения студентов-психологов.

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в браузере.

Для полноценной работы PWA и Service Worker рекомендуется запускать через локальный сервер, например расширение **Live Server** в VS Code.

## Публикация через GitHub Pages
1. Создайте публичный репозиторий GitHub.
2. Загрузите содержимое папки проекта в корень репозитория.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите ветку `main` и папку `/root`, затем Save.
6. Дождитесь публикации и откройте выданную GitHub Pages ссылку.

## Что реализовано
- гостевой режим без регистрации;
- дневник реакций с локальным сохранением;
- демонстрационная рефлексивная аналитика (не подключена внешняя языковая модель);
- шесть упражнений;
- история записей и выполненных упражнений;
- подготовка и сохранение материалов для супервизии;
- экспорт локальных данных в JSON;
- игровая механика «Живое дерево»;
- адаптивный интерфейс;
- базовая PWA-структура.

## Ограничения этой версии
- данные хранятся только в текущем браузере и на текущем устройстве;
- нет облачной базы и синхронизации;
- нет регистрации и аккаунтов;
- модуль ИИ пока демонстрационный, не отправляет данные внешнему сервису;
- push-уведомления не подключены.

Не вводите персональные или идентифицирующие данные клиентов.
